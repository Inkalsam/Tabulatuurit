# Tablulatuurit

# Sovelluksen toiminnnot
Sovelluksessa käyttäjät pystyvät jakamaan tabulatuureja ja sointuja kappaleiden kitaraosioista. 
Käyttäjä pystyy luomaan tunnuksen ja kirjautumaan sisään sovellukseen.
Käyttäjä pystyy lisäämään sovellukseen tabulatuureja ja muokkaamaan ja poistamaan niitä.
Käyttäjä näkee sovellukseen lisätyt tabulatuurit.
Käyttäjä pystyy etsimään tabulatuureja hakusanalla tai muulla perusteella. 
Sovelluksessa on käyttäjäsivut, jotka näyttävät jokaisesta käyttäjästä tilastoja, kuten arvostelut tabulatuurien tarkkuudesta ja käyttäjän lisäämien tabulatuurien määrän.
Käyttäjä voi valita esimerkiksi seuraavia luokitteluja: 
Genre: Rock, Metal, Pop jne.
Vaikeus: Kokenut, keskiverto, aloittelija.
Käyttäjät pystyvät kommentoimaan ja antamaan arvosanan tabulatuureista.
